# 官网待迭代清单

> 记录于 2026-10-25。来源：v6 首页第四轮（面向付费客户的专业定位）完成后，与用户确认的迭代方向。做完一项就在这里标记「已完成 + 日期 + 提交」，不另建第二份清单。

目标：让潜在付费客户在下单前回答三个问题——**你帮别人做成过什么、找你之后会发生什么、你是否可信。** 首页已讲清「会什么」，下面补齐后两点。

## P0：先做

### 1. 客户案例页
- 3～5 个完整案例，每个写清：客户画像（可匿名，如「某 10 人电商团队」）、起点问题、做了什么、结果数字、周期。
- 真实反馈尽量带署名、头像或聊天截图（须对方同意公开）。
- 首页能力卡的「案例」链接与合作段反馈改为指向案例页。
- 依赖用户提供：2～3 个真实项目的经过与数据、反馈公开授权。

### 2. 服务详情页
- 一对一咨询、AI 落地陪跑、知识星球各一页：适合谁 / 不适合谁、流程、交付物、预约后的步骤、FAQ、退款规则。
- 陪跑至少给出「¥X 起」的参考价，替代现在的「按项目」。

### 3. 站内直接预约与支付
- 现状：「预约咨询」跳转 `/links#offers`，多一步。
- 目标：在站内选时间、付款、收到确认（可先接现有收款方式 + 日程工具）。

## P1：信任基础

### 4. 专属域名与邮箱
- 现状：官网在 `aitongban.cloud`（AI 童伴产品名），联系邮箱为 163。
- 目标：个人品牌独立域名 + 同域名邮箱；旧域名 301 跳转。按 `docs/deployment.md` 执行，需用户授权。

### 5. 补充社会证明数字
- 各平台粉丝数、知识星球人数、累计服务人数、产品下载 / 用户数、合作公司或社区、演讲与分享记录。
- 数字须有出处，写入数据文件，按时更新。

### 6. 留资入口
- 现状只有 RSS。
- 提供免费资料（如「小团队 AI 落地检查清单」）换取邮箱或微信，用于长期触达与转化。

## P2：内容与表达

### 7. 文章专题化
- 按「AI 原生开发 / AI 助理与知识系统 / AI 内容生产 / 产品从 0 到 1」整理专题页，与首页四项能力一一对应。

### 8. 1～2 分钟自我介绍视频
- 放在关于页或首屏，口播形式。

## 工程：文章同步自动化

- 现状（见 `docs/content-workflow.md`）：正文在 `~/moonlit-creator` 维护；`content:discover` 发现新稿 → 手动在 `content/catalog/` 登记 → `npm run build` → `npm run pack` → 手动部署。没有定时任务。
- 目标：定时运行 `content:discover`，发现新的公众号文章后自动生成 catalog 草稿与预览，用户确认后再构建发布。
