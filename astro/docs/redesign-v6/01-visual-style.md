# 01 · 视觉风格

## 1. 参考站拆解（lizheng.ai，2026-10-25 采集）

只学结构和气质，不抄颜色、文案、Logo、人物和社区功能。

| 维度 | 参考站做法 | 我们学什么 |
| --- | --- | --- |
| 整体节奏 | 深绿 / 米白 / 浅米三种底色的整幅分段交替，每段一个主题 | 用整幅色带分段，让长页面有呼吸和章节感 |
| 标题 | Noto Serif SC 900，H1 84px、H2 46px，字距 +0.02em，句末带中文句号 | 宋体粗标题 + 短句 + 句号，形成“人写的”语气 |
| 正文 | 系统黑体 16–18.5px，行高 1.85，浅色文字在暗底上降到 74% 透明度 | 正文克制，标题与正文字体反差大 |
| 主视觉 | 人物抠图 + 背后超大书法字「立正」，人物底部被下一段色带切断 | 人物抠图 + 背后超大宋体「月」，底边贴住下一段 |
| 信息密度 | 履历横向时间轴、数字统计、评价、对话、书、判断、文章、合作，逐段展开 | 每段只讲一件事，顶部「eyebrow 小标 + 大标题 + 右侧说明」固定句式 |
| 组件 | 细线分隔、细描边卡片、10px 圆角按钮、文字链接 + 箭头 → | 线多于面，卡片少而准 |
| 动效 | 数字滚动、轮播淡出、时间轴节点高亮，整体很安静 | 只做进入视口的轻量出现，不做背景常驻动画 |

## 2. 月明Verse 的风格定义

关键词：**月夜、纸面、编辑部、安静的自信、做出来的东西**。

- 「月明」= 夜里清亮的月光。暗色段用 **深夜蓝**（不是黑、不是绿），亮色段用 **月白纸色**；点缀用现有品牌的 **铜橙**，暗底上换成更亮的 **月晕铜**。
- 「水清」= 透、静。不用渐变霓虹、不用玻璃拟态、不用大面积发光。唯一允许的光：Hero 暗段中极淡的一团蓝紫月晕（呼应蓝紫光环头像），静态径向渐变。
- 语气：短句、陈述、句号收尾。标题像一句话，而不是一个口号或名词。示例：「一个人做产品。做内容，也做增长。」「把做事的方法，开源成可用的工具。」「思考的过程，也值得留下。」

## 4. 字体

- 标题（H1–H3、大数字、时间轴节点名、文章标题）：`Noto Serif SC`，900 / 700 两个字重；回退 `'Songti SC', STSong, serif`。
- 正文与 UI：沿用 `--brand-font`（`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`）。
- 等宽数字（日期、Star 数、计数）：`font-variant-numeric: tabular-nums`，用正文字体即可。
- 拉丁字母与中文混排时，标题内的英文产品名（CreatorOS、ThirdSpace）同样走衬线，不单独换字体。
- 字体加载方式见 02 §2，必须子集化，不允许整包加载 Noto Serif SC。

## 5. 图像

1. **Hero 人像**：使用现有 `src/assets/moonlit/portrait.png`（官网主形象）制作 **透明底抠图版** `src/assets/moonlit/portrait-cutout-v1.png`。
   - 只做去背景（rembg / 同类工具），不做任何 AI 重绘、换脸、美颜、改衣服。边缘做 1–2px 羽化，检查头发和手臂边缘无白边。
   - 裁成半身（头顶到腰下），人物底边与 Hero 段底边齐平。
   - 抠图原件与处理说明保存到 `design/redesign-v6/portrait/`。抠图质量不合格时，降级为方案 B：原图放在 `--radius-lg` 圆角框内，背后仍有「月」字。
2. **背景大字「月」**：HTML 文本（不是图片），Noto Serif SC 900，`--moon-cream` 色 92% 不透明，桌面字号约 520px，位于人物身后、向右溢出被裁切。必须 `aria-hidden="true"`。
3. **产品 / 开源 / 文章配图**：全部沿用 `design/visuals/registry.json` 与现有封面，不重新生成。暗段里的产品卡片保留图片原色，不加滤镜改色。
4. 禁止：宇航员 IP、霓虹、赛博线框、AI 生成的人像替身、库存照片、伪造截图。

## 6. 动效原则

- 总体：**安静**。页面静止时没有任何在动的东西。
- 允许：
  - 进入视口的出现：`opacity 0→1` + `translateY 12px→0`，240–360ms，`cubic-bezier(.2,.7,.2,1)`，同组错开 60ms，只播一次。
  - 数字统计：进入视口时从 0 滚到终值，≤ 900ms。**无 JS / 减少动态效果时直接显示终值**（参考站截图里出现过“0K”，这是要避免的缺陷）。
  - 时间轴：最后一个节点（当前）有一个静态实心高亮点；不做循环脉冲。
  - 卡片悬停：产品与开源图片卡继续用 `CardEffect.astro`；文字列表行悬停只做底色 3% 加深 + 箭头右移 4px。
  - 按钮悬停：背景色变化 160ms，不位移、不放大。
- 取消：首页及列表页的 `SiteAtmosphere` WebGL 背景、32px 网格、`hero-motion.ts` 中鼠标跟随类动效（若有）。实现方式：页面不再引用即可，文件保留，`SiteLayout` 增加 `atmosphere?: boolean` 参数默认 `false`。
- `prefers-reduced-motion: reduce`：关闭所有位移与数字滚动，只保留颜色变化。
